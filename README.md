# DiceBattle

Javaの学習課題として制作した、コンソール上で動作するターン制バトルゲームです。

講師から提示された要件をもとに制作しました。

[課題として提示された要件](./src/main/KadaiBun.java)

## 使用技術

- Java

## 継承と多態性

異なるキャラクター・行動・状態異常をそれぞれ`Character`、`Command`、`Abnomal`としてまとめて扱い、共通の処理から実行できる構成としました。

## 行動の予約と実行

各キャラクターの行動は、実行する`Command`と対象を決定したうえで、一度実行待ちのリストへ登録する構成としました。

全キャラクターの行動選択が完了した後、登録された`Command`を優先度に応じて順番に実行します。

この構成により、「防御を攻撃より先に処理する」といった行動順の制御を、各キャラクターの処理から分離しています。
